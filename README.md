# 自动答题程序（OCR 识别版）

> 一款基于 OCR 文字识别的题目匹配工具，导入题库后，根据识别到的题目给出对应答案。

## 📖 使用指南

### 功能简介

程序打开后即为自动识别显示界面，主要包含以下功能：

- **答题设置**：开启后自动识别题目；题目未匹配时，可通过 OCR 快速补充答案
- **区域框选**：框选题目关键词区域与正确答案区域，精准定位识别范围
- **识别历史**：记录识别记录，方便后续修改题库；未匹配的题目单独列出
- **OCR 缩放倍率**：控制截图识别的放大/缩小比例，倍率越大识别越精准但速度越慢
- **匹配阈值**：控制识别文字与题库文字的匹配度，值越高匹配越精准，值越低越宽松
- **题库管理**：查看当前导入的题库，支持从外部导入题库

### 快速开始

1. **导入题库**：在「题库管理」中导入题库文件（也可从外部导入）
2. **框选区域**：在「答题设置」中框选题目关键词区域和正确答案区域
   - 框选范围越小，抽取答案速度越快，但可能匹配不精确
   - 框选后点击「测试截图」确认识别是否准确
   - **别忘了点击保存，使框选生效**（正确答案区域同理）
3. **调整参数**：根据识别情况调整 OCR 缩放倍率与匹配阈值
4. **开始识别**：开启自动识别，即可在答题时自动显示对应答案

### 参数说明

| 参数 | 说明 |
| --- | --- |
| OCR 缩放倍率 | 截图识别的放大缩小倍率。越大识别越精准但速度越慢；越小反应越快但准确率越低 |
| 匹配阈值 | 识别文字与题库文字的匹配度。值越高匹配越精准；值越低匹配越宽松 |

### 常见问题

- **外部题库如何生效？** 在「题库管理」导入后，退出并重新打开程序即可使用。
- **识别不准怎么办？** 尝试增大 OCR 缩放倍率、提高匹配阈值，或缩小框选范围让定位更精准。
